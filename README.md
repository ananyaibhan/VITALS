# Blood Bank Optimizer

An ML project for optimizing blood bank operations, including forecasting inventory and managing expiry risk.

## Folder Structure

- `data/`: Raw and processed datasets.
- `notebooks/`: Data exploration and research.
- `src/`: Core logic (validation, features, models, optimization).
- `models/`: Serialized model artifacts.
- `pipelines/`: Orchestration and processing pipelines.
- `deployment/`: API and Docker configurations.
- `monitoring/`: Model performance tracking.

## Getting Started

1. Set up virtual environment: `python3 -m venv venv`
2. Activate: `source venv/bin/activate` or `source venv/bin/activate.zsh`
3. Install: `pip install -r requirements.txt`
